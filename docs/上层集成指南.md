# EtherCAT 驱动上层集成指南

本文档描述底层 EtherCAT CiA402 驱动的数据接口，供上层控制系统集成使用。

---

## 1. 系统概述

### 1.1 控制频率

- **控制周期**: 1000 Hz（1 kHz）
- **PDO 通信**: 周期性同步数据交换，无需上层介入
- **状态发布**: `MotorDataBroadcaster` 以控制周期（1 kHz）发布电机数据

### 1.2 多电机配置

当前 URDF 默认定义 3 个电机（`motor_joint_1/2/3`），通过修改 URDF 和 `controller.yaml` 中的 `motor_count` 及 `motor_names` 可扩展至更多电机。

---

## 2. 数据读取接口（TPDO — 从电机读取）

### 2.1 TPDO 反馈数据

电机通过 TPDO 通道周期性上传以下数据：

| 对象索引 | 名称 | 数据类型 | 说明 |
|---------|------|---------|------|
| 0x6041 | Status Word | uint16 | CiA402 驱动器状态字 |
| 0x6064 | Position Actual Value | int32 | 当前位置值（编码器计数） |
| 0x606C | Position Actual Velocity | int32 | 实际速度（计数/s） |
| 0x6061 | Modes of Operation Display | int8 | 当前运行模式 |

### 2.2 ROS 消息格式

`MotorDataBroadcaster` 节点以 1 kHz 频率发布至 `/MotorDataBroadcaster/motor_data_topic`，消息类型 `mpk_ethercat_test/msg/MotorDataArray`：

```msg
std_msgs/Header header
MotorData[] motors
```

`MotorData`（每个电机一条）：

| 字段 | 类型 | 说明 |
|------|------|------|
| header | std_msgs/Header | 时间戳 |
| motor_name | string | 电机名称（如 "motor_joint_1"） |
| motor_index | int32 | 零基索引 |
| status_word | uint16 | 原始状态字（0x6041） |
| actual_position | int32 | 原始编码器位置（计数） |
| actual_velocity | int32 | 原始速度值（计数/s） |
| operation_mode | int8 | 当前运行模式 |
| actual_physical_position | float64 | 转换为物理单位后的位置（单位由 screw_lead_mm_per_rev 决定，默认 mm） |
| actual_physical_velocity | float64 | 转换为物理单位后的速度（单位由 screw_lead_mm_per_rev 决定，默认 mm/s） |

### 2.3 ros2_control 状态接口（每个电机 4 个）

接口声明顺序：**position → velocity → status_word → op_mode**

| 接口名 | 类型 | 说明 |
|--------|------|------|
| `position` | double | 实际位置（编码器计数） |
| `velocity` | double | 实际速度（计数/s） |
| `status_word` | double | 状态字原始值（uint16） |
| `op_mode` | double | 当前运行模式（int8） |

## 3. 数据下发接口（RPDO — 向电机写入）

### 3.1 RPDO 命令数据

| 对象索引 | 名称 | 数据类型 | 说明 |
|---------|------|---------|------|
| 0x6040 | Control Word | uint16 | CiA402 状态机控制字 |
| 0x607A | Target Position | int32 | 目标位置（计数） |
| 0x60FF | Target Velocity | int32 | 目标速度（计数/s） |
| 0x6060 | Modes of Operation | int8 | 目标运行模式 |

### 3.2 ros2_control 命令接口（每个电机 4 个）

接口声明顺序：**control_word → op_mode → position → velocity**

| 接口名 | 类型 | 说明 |
|--------|------|------|
| `control_word` | double | 控制字（uint16） |
| `op_mode` | double | 目标运行模式（int8） |
| `position` | double | 目标位置（计数） |
| `velocity` | double | 目标速度（计数/s） |

### 3.3 Topic 命令接口

通过 `ForwardCommandController` 暴露为 Topic，消息类型均为 `std_msgs/Float64MultiArray`：

| Topic | 说明 |
|-------|------|
| `/control_word_controller/commands` | 控制字数组 |
| `/op_mode_controller/commands` | 运行模式数组 |
| `/position_controller/commands` | 目标位置数组 |
| `/velocity_controller/commands` | 目标速度数组 |

数组元素顺序与 `controller.yaml` 中 `joints` 列表一致（motor_joint_1, motor_joint_2, ...）。

### 3.4 CSP 模式下必须持续发送 Enable 命令

**重要**: 进入 Operation Enabled 后，驱动器需要每周期持续收到 `0x000F` 控制字。若停止发送，驱动器会从 Operation Enabled 回退至 Switched On 状态。实现自动状态推进的 GUI 代码在检测到 Operation Enabled 后，会将发送的控制字从 `0x0007` 切换为 `0x000F` 并持续发送。

## 4. CiA402 状态机

### 5.1 状态定义

| 状态 | 状态字值（bits 0-3,5,6） | 说明 |
|------|------------------------|------|
| Not Ready to Switch On | 0x00 | 驱动器未初始化 |
| Switch On Disabled | 0x40 | 切换禁止 |
| Ready to Switch On | 0x21 | 等待上电 |
| Switched On | 0x23 | 已上电，等待使能 |
| Operation Enabled | 0x27 | 运行使能（正常工作状态） |
| Quick Stop Active | 0x07 | 快速停止中 |
| Fault Reaction Active | 0x0F | 故障反应中 |
| Fault | 0x08 | 故障 |

快速判断 Operation Enabled：`status_word & 0x6F == 0x27`

### 5.2 关键控制字

| 控制字 | 值 | 触发转换 |
|--------|-----|---------|
| Shutdown | 0x0006 | 任何状态 → Ready to Switch On |
| Switch On | 0x0007 | Ready to Switch On → Switched On |
| Enable Operation | 0x000F | Switched On → Operation Enabled |
| Disable Voltage | 0x0000 | 任何状态 → 电压禁止（紧急停机）|
| Fault Reset | 0x0080 | Fault → Switch On Disabled |
| Quick Stop | 0x0002 | Operation Enabled → Quick Stop Active |

### 5.3 使能序列

完整使能需按序发送（通常间隔 80-240 ms）：

```
0x0080 (Fault Reset) → 0x0006 (Shutdown) → 0x0007 (Switch On) → 0x000F (Enable)
```

## 5. 运行模式

### 6.1 支持的模式

| 代码 | 模式 | 说明 |
|------|------|------|
| 3 | Profiled Velocity (PV) | 速度包络模式 |
| 6 | Homing | 回零 |
| 8 | Cyclic Sync Position (CSP) | 周期同步位置（推荐） |
| 9 | Cyclic Sync Velocity (CSV) | 周期同步速度 |

### 6.2 CSP 模式（Cyclic Sync Position，推荐）

上位机以 1 kHz 周期下发目标位置，驱动器内部插补。适合高精度轨迹跟踪。

- **目标位置单位**: 编码器计数（int32）
- **周期**: 1 ms（1 kHz），由 `0x60C2` 配置（time base 10^-3 s）

### 6.3 CSV 模式（Cyclic Sync Velocity）

上位机以 1 kHz 周期下发目标速度。

- **目标速度单位**: 计数/s（int32），转换公式见 §7.2

## 6. 物理单位转换

驱动板卡内部以编码器计数为单位，`MotorDataBroadcaster` 自动完成转换后发布 `actual_physical_position` 和 `actual_physical_velocity`。如需自行计算：

### 7.1 位置转换

```
position_physical = (position_bias_count - actual_position) * screw_lead_mm_per_rev / encoder_counts_per_rev
```

物理单位由 `screw_lead_mm_per_rev` 决定（本项目默认为 mm）。其中 `position_bias_count` 为偏置计数值（通过 ROS 参数 `motor_X.position_bias_count` 动态配置）。

### 7.2 速度转换

```
velocity_physical = -actual_velocity * screw_lead_mm_per_rev / 1000.0
```

### 7.3 上层下发时的反向转换

**位置命令（编码器计数）**：
```
encoder_count = position_bias_count - target_physical * encoder_counts_per_rev / screw_lead_mm_per_rev
```

**CSV 速度命令（mrev/s）**：
```
velocity_mrev_per_s = -target_physical * 1000.0 / screw_lead_mm_per_rev
```

### 7.4 默认参数

| 参数 | 默认值 | ROS 参数名 |
|------|--------|-----------|
| encoder_counts_per_rev | 131072 | motor_X.encoder_counts_per_rev |
| screw_lead_mm_per_rev | 10.0（mm/rev） | motor_X.screw_lead_mm_per_rev |
| position_bias_count | 0 | motor_X.position_bias_count |

## 7. 控制器配置

### 8.1 控制器列表

| 控制器 | 类型 | 命令接口 |
|--------|------|--------|
| MotorDataBroadcaster | 自定义 | 无（只读） |
| control_word_controller | ForwardCommandController | control_word |
| op_mode_controller | ForwardCommandController | op_mode |
| position_controller | ForwardCommandController | position |
| velocity_controller | ForwardCommandController | velocity |

### 8.2 controller.yaml 结构

```yaml
controller_manager:
  ros__parameters:
    update_rate: 1000          # 必须与控制频率一致

MotorDataBroadcaster:
  ros__parameters:
    motor_count: 3
    motor_names: [motor_joint_1, motor_joint_2, motor_joint_3]
    motor_1: { position_bias_count: 0, encoder_counts_per_rev: 131072, screw_lead_mm_per_rev: 10.0 }
    motor_2: { position_bias_count: 0, encoder_counts_per_rev: 131072, screw_lead_mm_per_rev: 10.0 }
    motor_3: { position_bias_count: 0, encoder_counts_per_rev: 131072, screw_lead_mm_per_rev: 10.0 }

control_word_controller:
  ros__parameters:
    joints: [motor_joint_1, motor_joint_2, motor_joint_3]
    interface_name: control_word

position_controller:
  ros__parameters:
    joints: [motor_joint_1, motor_joint_2, motor_joint_3]
    interface_name: position
```

### 8.3 控制器启动顺序

启动文件（`test_multi_motor.launch.py`）中控制器按以下顺序级联启动：

```
MotorDataBroadcaster → control_word_controller → op_mode_controller → position_controller → velocity_controller
```

每一级在上一级成功退出后启动，确保状态机控制字优先于位置/速度命令生效。

## 8. 典型集成流程

### 9.1 启动流程

```
1. ros2 launch mpk_ethercat_test test_multi_motor.launch.py
2. 等待所有电机进入 "Switch on disabled" 或 "Ready to switch on" 状态
3. 按序发送使能控制字：0x0006 → 0x0007 → 0x000F
4. 发送目标运行模式（如 8 for CSP）
5. 激活 position_controller，开始周期下发目标位置
```

### 9.2 CSP 周期控制循环（1 kHz）

```
for each 1ms cycle:
    1. 读取 /MotorDataBroadcaster/motor_data_topic 获取当前状态
    2. 上层轨迹规划计算下一步目标位置（物理单位）
    3. 将目标物理单位转换为编码器计数
    4. 发布 Float64MultiArray 到 /position_controller/commands
    5. 同时发布 0x000F 到 /control_word_controller/commands（持续保持）
```

### 9.3 紧急停止

发布控制字 `0x0000` 到 `/control_word_controller/commands`，立即切断所有电机输出。

### 9.4 动态调整参数

通过 ROS 参数实时调整，无需重启：

```bash
# 调整电机 1 的位置偏置
ros2 param set /MotorDataBroadcaster motor_1.position_bias_count 3373839

# 调整电机 2 的丝杠导程
ros2 param set /MotorDataBroadcaster motor_2.screw_lead_mm_per_rev 5.0
```

## 10. 错误处理

### 10.1 状态字错误标志

| 位 | 错误码 | 含义 |
|----|--------|------|
| 3 | 0x2310 | DC link undervoltage（直流母线欠压）|
| 4 | 0x3210 | DC link overvoltage（直流母线过压）|
| 5 | 0x2210 | Drive overcurrent（驱动过流）|
| 6 | 0x4210 | Drive overtemperature（驱动过热）|
| 7 | 0x8A10 | Position limit exceeded（位置超限）|
| 8 | 0x8310 | Speed limit exceeded（速度超限）|
| 9 | 0x8410 | Torque limit exceeded（转矩超限）|

### 10.2 故障恢复步骤

```
1. 读取 status_word 分析故障类型
2. 消除故障根源
3. 发送 0x0080（Fault Reset）
4. 等待状态切换至 Switch On Disabled
5. 重新执行使能序列
```

## 11. 多电机索引约定

- `motor_index`（消息中）：零基索引，0 ~ motor_count-1
- 参数前缀：`motor_1`, `motor_2`, ...（**从 1 开始**）
- joint 名称：`motor_joint_1`, `motor_joint_2`, ...（从 1 开始）
- ROS Topic 数组顺序：与 `controller.yaml` 中 `joints` 列表一致
